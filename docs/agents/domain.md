# Domain docs

This repository uses a single context. Read root `CONTEXT.md` before exploring domain concepts, and read relevant ADRs in `docs/adr/` before changing an area they cover.

These files are created when domain terms or decisions are established; their absence does not block other work.

Use terms from `CONTEXT.md` in issues, proposals, and code. If a needed concept is absent, raise it for domain modeling. If a proposal conflicts with an ADR, identify the ADR and explain the conflict.

Layout:

```
/
├── CONTEXT.md
├── docs/adr/
└── src/
```
