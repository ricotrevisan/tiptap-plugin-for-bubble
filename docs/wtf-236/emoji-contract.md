# WTF-236 — Emoji slice

Audio and Twitch remain out of scope. This slice uses the free `@tiptap/extension-emoji@3.31.3` inline **node**, not a Bubble picker. The editor converts recognized `:shortcode:` and known Unicode emoji typed or pasted in editable content into nodes (except inside code blocks); **Insert emoji** accepts a catalog name (`smile`) or a wrapped shortcode (`:smile:`), not a Unicode character. An empty or unknown name leaves content unchanged and reports a debugger message.

- Emoji is off by default. With it off, the node is absent from the schema, input rules do not run, and Insert emoji reports it is unavailable. Enabling it on a live editor rebuilds without losing unsaved content. Disabling it converts existing emoji nodes to readable Unicode text (or `:name:` if no catalog item exists) before rebuilding; this is deliberately lossy. Every collaborating editor for a document must enable Emoji or a peer without the node can strip its structure.
- The node's ProseMirror JSON stores `{ "type": "emoji", "attrs": { "name": "smile" } }`. HTML includes `span[data-type="emoji"][data-name="smile"]` with Unicode when supported and an `img` from the upstream Apple catalog on unsupported devices. Images load from `cdn.jsdelivr.net`; they are not uploaded to Bubble. The HTML child may differ between browser and server because emoji font/canvas support differs. The *node identity* and readable presentation round-trip; a webhook converts the same JSON with the same extension and fallback catalog, but byte-identical HTML across devices is not promised.
- Read-only editors load and display emoji nodes without requiring an edit action. With Emoji off, loading HTML containing a fallback-image span may not recover its text; keep the extension enabled for stored emoji content.
- Off-default means no schema/plugin activity, **not** no download: this plugin loads one static Tiptap bundle for every editor. Baseline build: 1,456,994 bytes raw / 421,018 gzip. Emoji build: 1,984,525 bytes raw / 491,216 gzip, an increase of 527,531 raw / 70,198 gzip. Assets for fallback images are separate on-demand network requests. No threshold was specified in the issue; the maintainer accepted this measured cost for the Emoji slice.

Test cases: disabled action and schema; toggle on preserves unsaved text; workflow insertion by name and shortcode; unknown/empty no-op; HTML and JSON round-trip; typed shortcode/Unicode and alias; image fallback; toggle off preserves readable text; read-only rendering; webhook conversion.
